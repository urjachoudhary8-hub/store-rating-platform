# Store Rating Platform

A web-based application that allows users to explore stores and submit ratings. The platform supports different user roles to manage store information and ratings.

## Features

- User registration and login
- Role-based access for Admin, Store Owner, and User
- Store listing and rating submission
- Rating management and average rating display
- Admin management of users and stores

## Tech Stack

- **Frontend:** Check project configuration
- **Backend:** Node.js
- **Language:** TypeScript
- **Package Manager:** npm

## Project Structure

- `server/` — Server-side code
- `src/` — Application source code
- `package.json` — Project dependencies and scripts
- `.env.example` — Example environment configuration

## Run Locally

### Prerequisites
- Node.js and npm installed

### Installation

1. Clone this repository:
   `git clone https://github.com/urjachoudhary8-hub/store-rating-platform.git`

2. Open the project folder:
   `cd store-rating-platform`

3. Install dependencies:
   `npm install`

4. Check `package.json` for the available start or development script.

5. Configure the required environment variables using `.env.example`.
